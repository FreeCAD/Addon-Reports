Weighted load = 10·HIGH + 1·MEDIUM + 0.1·LOW (HIGH weighs 10× MEDIUM, MEDIUM weighs 10× LOW). Per-addon Quality Index = max(0, 100 − 11·ln(1 + load)) — logarithmic so no saturation; halving an addon's weighted load always earns the same points. The headline index is the mean across addons (optionally severity-weighted, see chart selector).
Vendored code = paths matching /vendor/ · /libs/ · /site-packages/ · /third-party/ …; the scope selector on "Issues over time" counts only first-party or only vendored findings. Issue-type keys normalize texts (lowercase, digits → #). Staleness uses each entry's last-commit timestamp. Category INFO is excluded from every metric, delta and chart on this page.
